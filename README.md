# Пиксельная песочница

Браузерная «падающая песочница» (falling-sand game): выбираешь вещество, рисуешь им по полю и смотришь, как частицы сыплются, текут, горят, плавятся, взрываются и проводят ток. Под капотом — клеточная симуляция с температурой, давлением воздуха, герметичными полостями и электричеством.

Проект без зависимостей и сборки: чистые HTML, CSS и JavaScript.

## Запуск

Откройте `index.html` в браузере. Можно и через любой статический сервер:

```sh
python3 -m http.server 8000
# затем http://localhost:8000
```

Нужен интернет только для шрифтов Google Fonts. Без него игра тоже работает, но со стандартными шрифтами.

## Управление

| Действие | Ввод |
| --- | --- |
| Сыпать выбранное вещество | ЛКМ (или касание) |
| Стирать | ПКМ или инструмент «Ластик» |
| Пауза / продолжить | `Пробел` |
| Размер кисти | `[` и `]` или ползунок «Кисть» (0–20) |
| Режим просмотра | `1` вещества, `2` температура, `3` давление |

Кнопки под полем:

- **Шаг** — один тик симуляции (ставит на паузу).
- **Скорость** — ×1, ×2, ×4.
- **Демо-сцена** — загружает готовую сцену с примерами.
- **Очистить** — очищает поле (нужно нажать дважды для подтверждения).

Строка над кнопками показывает вещество под курсором, его температуру, давление, признак закрытой полости и наличие тока, а также число частиц и FPS.

## Вещества

| Группа | Вещества |
| --- | --- |
| Твёрдые | Стена, Дерево, Растение, Лёд, Металл, Ржавчина, Стекло |
| Сыпучие | Песок, Камень, Соль, Снег, Порох, Земля, Грязь, Пепел, Опилки |
| Жидкости | Вода, Лава, Масло, Солёная вода, Кислота, Нитро |
| Газы и огонь | Огонь, Дым, Пар, Газ, Угли |
| Особые | Клон, Пустота, Нагреватель, Охладитель, Батарея, Ластик |

При выборе вещества под полем появляется его описание. Несколько примеров взаимодействий:

- Песок выше 1000 °C плавится в стекло, лава ниже 750 °C застывает в камень.
- Вода кипит при 100 °C (под давлением позже), замерзает ниже 0 °C, растворяет соль, превращает землю в грязь, ржавит металл.
- Порох и нитро в замкнутом сосуде создают давление, которое рвёт стенки. Стекло от давления бьётся, металл почти всё выдерживает.
- **Клон** запоминает первое коснувшееся вещество и бесконечно его производит, а **Пустота** уничтожает всё вокруг.
- **Батарея** пускает искры по металлу и воде; ток в солёной воде разлагает её на горючий газ.
- **Нагреватель** держит 1500 °C, **Охладитель** — −150 °C.

## Сохранение сцен

В боковой панели, в разделе «Сцены»:

- **3 слота** сохраняются в `localStorage` браузера.
- **Код сцены** — строка base64, которой можно поделиться: «Скопировать код» кладёт её в буфер обмена, «Загрузить из кода» восстанавливает сцену из вставленной строки.

Формат кода: RLE-сжатые типы частиц, температуры (шаг 10°), количество газа в клетках и память клонов.

## Как устроено

```
index.html   разметка интерфейса
style.css    оформление
script.js    движок симуляции, рендеринг и UI
```

Основные моменты `script.js`:

- Поле 256×160 частиц. Все свойства хранятся в типизированных массивах (`type`, `temp`, `life` и т. д.).
- Вещества описаны в массиве `DEFS`: тип (твёрдое, сыпучее, жидкость, газ, огонь), плотность, растекаемость, горючесть, температура воспламенения, теплопроводность, электропроводность, прочность и во что вещество разрушается.
- Воздух моделируется отдельной сеткой 128×80 (одна клетка на 2×2 частицы) с давлением и скоростью. Ударные волны двигают частицы и ломают непрочные материалы.
- Замкнутые полости находятся заливкой. Давление в них считается по закону идеального газа: количество газа × абсолютная температура / свободный объём.
- Каждый тик выполняются теплопередача, распространение искр (голова/хвост волны) и обновление частиц.
- Отрисовка идёт в `ImageData` холста. Режимы «Температура» и «Давление» раскрашивают поле градиентом с легендой.

Чтобы добавить вещество, допишите объект в `DEFS` (поля описаны в комментарии над массивом), а особое поведение — в функцию `update`.
